# portfolio-site

> Personal portfolio — Muhammad Rehan Saeed, Crypto Systems Engineer.

**Live:** https://rehansaeedjutt-rgb.github.io/portfolio-site/

## What this is

A single-page portfolio built by hand — no framework, no build step, no trackers.
Just `index.html`, `styles.css`, and `.nojekyll`. Hosted free on GitHub Pages.

## Design

- Dark theme with cyan accent
- Monospace headers for an engineer aesthetic
- Project cards with tech tags and honest coverage metrics
- Responsive: single column on mobile, 3-column grid on desktop

## Structure

    portfolio-site/
    index.html        Single-page site
    styles.css        All styling (dark theme, responsive)
    .nojekyll         Ensures GitHub Pages serves files as-is

## Local preview

Open `index.html` directly in a browser — no server needed.
